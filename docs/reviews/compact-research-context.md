## 修改范围

基于 PR #22 合并提交 `5cf589079b9ae926546a10c09e72da5ff030737d`，只调整已有五工具的阅读交付和调用说明。搜索、排名、来源资格、证据身份及分页算法未修改，未重建数据库、索引或向量。

搜索的 reading 视图继续保留每条命中的 exact ref、顺序、摘录、proof、过滤和 cursor；重复的容器/来源定位改用 scoped handles，预览使用独立正文 handle。可直接执行的动作参数只包含工具参数，以返回的 handle 定位。原 `original_items_and_cursor_unchanged` 在此视图为 false，另以 `hit_identity_order_and_cursor_unchanged=true` 区分命中不变和展示字段精简。

对白边及显式 `follow_evidence(detail="reading")` 用短 handle 交付重复定位；follow 原默认 full 保持。单条普通 inspect 仍默认 full；只需核验状态时可用 reading，多条最终材料优先现有批量 inspect。不同 observation/range 和正文 handle 不合并；重复纯定位可共享同一次请求的 locator handle，始终标记未读。

完整原始工具结果先进入不可变映射，之后才精简显示；full 请求和正式 inspect 仍还原原始 exact identity。未知、过期或跨连接 handle 拒绝，不猜测恢复。没有依据答案内容更换引用、补充 claim 或认定逻辑关系。调用方法见 [对白阅读](../guides/reading-dialogue.md)。

对同一保留的正式有界 7.1 数据，分别用合并基线和修改源码启动真实 stdio MCP。每侧20次程序化调用，一次对照，均执行正常来源资格核验；不是自主模型矩阵。先通过来源 Document 标题导航到实际 Readable 正文，检查5个物理行，并读取 Character Story、两页 Dialog 正文及最终集合卡。

## 回归及限制

Linux 完整合成回归779项通过、3项跳过；最终受影响的展示、实际 stdio、来源卡、引用交付、管线及仓库/CI规范91项通过。编译与六命令 help 通过；本地链接和许可检查包含于规范测试。完整回归后的小改动为说明和 compact 元数据标记，已包含最终定向检查。Windows 由本分支 CI 单列，不沿用旧提交结果。

新增测试核对完整身份与短定位、动作参数实际执行、预览不得冒充已读正文、不同 observation、目标顺序与候选状态、导航正式回读和无效 detail。既有范围、跨连接/损坏 handle、引用渲染及分页负测保留。近字节上限的不可精简 fixture 保留原 exact-ref 回退门槛；可精简结果另验证 handle 映射。

初轮定向4项失败涉及旧展示字段/上限假设；更新为逐项正式回读的断言后，又保留了新增核验导致回执数量断言失败的3项诊断，再修正测试计数位置。诊断脚本早期只读到素材书名、未读到正文的记录不算正文验收；最终通过已声明 Document→Readable 目标读取实际正文。失败、原始调用、映射和卡片只保留在私有验证目录，不提交游戏文本或个人配置。

没有完整35输入重建、发布资格变更、本机 MCP 自动部署或原生 Codex renderer 修改。短 handle 仍仅在原连接有效；详细 provenance、文件级链接和完整关系结构按需取 full。已经读过的材料按需复用，继续调查应解决具体缺口；这不是降低引用或研究深度要求。
